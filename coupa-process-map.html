🔄 Retry implementation
async def post_comment_with_retry( self, invoice_id: str, comment: str ) -> bool: for attempt in range(3): try: resp = await self.client.post( f"/invoices/{invoice_id}/comments", json={...} ) if resp.status_code == 201: return True except Exception as e: logger.warning(f"Attempt {attempt+1} failed: {e}") await asyncio.sleep(5) # All 3 retries failed — email fallback await notifier.send_fallback_email(invoice_id, comment) return False
⚠ Never-silent failure policy
Every error must surface somewhere:

1. First: retry the operation
2. On failure: email fallback to SUPPORT_EMAIL
3. Always: log to agent.log with full traceback
4. Always: write to audit_log.jsonl
5. Always: update state.json

No invoice should be left in an unknown state. If the agent cannot determine what happened, it escalates rather than silently continuing.
