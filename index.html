What makes this true agentic AI
v3.0 upgrade
Claude is now the orchestrator — not a tiebreaker at the end of a pipeline
The original design was sophisticated RPA — a hardcoded sequence that called Claude only when it got confused. v3.0 redesigns the core: Claude receives the invoice ID and 12 tools, then decides everything autonomously — which tools to call, in what order, what action to take, and what to write in Coupa. No fixed sequence. No templates.
🔨 Tool-use architecture
12 tools available. Claude decides which to call and when — fetch, validate, cross-check, act, escalate, learn. No hardcoded order.
🧠 Long-term memory
vendor_patterns.json grows with every invoice. Claude reads vendor history before validating — past failures shape current decisions.
🔄 Reflection + learning
store_reflection tool called after every invoice. Claude records patterns and suggests rule improvements. Gets smarter over time.
