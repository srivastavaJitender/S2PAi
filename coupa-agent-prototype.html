How the agent works
Zero manual intervention — fully autonomous end-to-end
🕐
Automatic polling every 10 minutes Fully automated
The agent continuously monitors Coupa for new invoices with status "draft" and AP hold code "Pending Agent Review". No human needs to trigger this — it runs 24/7 on a 10-minute cycle.
✓
Runs 2 validation checks in parallel
Tax validation checks that tax codes, rates, and amounts on every invoice line match Coupa master data. WHT validation checks that withholding tax codes applied on the invoice match the vendor master configuration.
🧠
Claude AI reasons about edge cases AI powered
For ambiguous or borderline cases, the agent calls Claude AI (Anthropic) to reason about the best action — submit, hold, or escalate. Claude considers context like number of previous attempts and whether issues are likely data-entry errors vs genuine compliance concerns.
▶
Pass → auto-submits for approval
If all checks pass, the agent automatically clears the AP hold code, posts a "Verified by Agent — OK to submit" comment in Coupa, and moves the invoice forward. No AP team action needed.
🔒
Fail → blocks and writes structured error comment in Coupa
If checks fail, the agent sets the invoice to on-hold and writes a detailed error comment directly into the Coupa comment box — exact line numbers, expected vs actual values, and corrective action required. The AP team sees this immediately in Coupa without needing to look elsewhere.
↻
Auto re-validates after AP fixes the invoice
Once the AP team corrects the invoice in Coupa, the agent detects the change on the next 10-minute cycle and automatically re-runs all validations. If it now passes, it auto-submits. If it still fails, it updates the error comment with the new findings.
Business benefits
⏰
Eliminates manual review time
AP team no longer manually checks tax codes and WHT codes before submission — the agent does it instantly and automatically, every invoice, every time.
~3 hrs/day saved

100% traceable

Risks and mitigations
⚠
Risk: Agent incorrectly holds a valid invoice. Mitigation: All validation logic mirrors existing n8n workflow exactly. AP team receives a detailed error comment and can override. The agent never deletes or modifies financial data.
⚠
Risk: Coupa API downtime disrupts the agent. Mitigation: Agent retries 3 times with exponential backoff, then logs the error and alerts the support team. No invoice is left in an unknown state.
⚠
Risk: Invoice data privacy — data processed by Claude AI. Mitigation: Only borderline edge cases are sent to Claude. Core validation logic is entirely local Python. Anthropic zero-data-retention API option available on request.
